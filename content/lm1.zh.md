## 一个操作,撑起整个架构

Transformer 里真正新的东西只有一个:**自注意力**。它做的事可以用一句话说完——让序列里每个位置去所有位置取一次加权平均。

具体是三步:

1. 每个 token 的向量分别乘三个矩阵,得到查询 **Q**、键 **K**、值 **V**。可以这样理解:Q 是「我在找什么」,K 是「我能提供什么」,V 是「我实际带的信息」。
2. 用 Q 和所有 K 做点积,得到一组相关性分数,除以 √d 之后过 softmax,变成一组和为 1 的权重。
3. 用这些权重对所有 V 加权求和,就是这个位置的输出。

写成公式就是 `Attention(Q,K,V) = softmax(QKᵀ/√d)·V`。上面推演里那张热力图,就是 `softmax(QKᵀ/√d)` 这个矩阵的一行。

**为什么这一步这么有用?** 因为它是唯一一个能让远距离的两个 token 直接交互的操作,而且代价和距离无关。在它之前,循环网络要把信息一步步传过去,传二十个词就衰减得差不多了。注意力里,第 1 个词和第 100 个词的距离和第 99 个词到第 100 个词一样近。

## √d 不是装饰

那个缩放因子的存在有一个非常具体的数值原因。两个 d 维向量的点积,如果每一维都是均值 0、方差 1 的随机数,那么点积的方差就是 d,标准差是 √d。所以 d 越大,点积的绝对值就越大。

而 softmax 有一个性质:输入的绝对值越大,输出越接近 one-hot。当 d=4096 时,不做缩放的点积能轻松到几十的量级,softmax 之后几乎所有概率都集中到一个位置——**其他位置的梯度全部接近 0,模型学不动了**。

除以 √d 正好把方差拉回 1,让 softmax 工作在它敏感的区间里。你可以在推演里把「除以 √d」关掉,把 d 拉到 1024,看最大权重怎么冲到 99% 以上。

顺便说一句,这个「除以一个数来控制分布尖锐程度」的操作,你在后面的解码策略一章会再见到一次,那里它叫**温度**。它们是同一个数学动作。

## 多头:同时看几种关系

一次注意力只能算出一种「相关性」。但语言里同时存在很多种关系:语法上的主谓搭配、指代关系、语义上的近义、以及位置上的邻接。

多头注意力的做法很直接:把 d 维切成 h 份(比如 4096 切成 32 个 128 维的头),每个头独立算一次注意力,最后把结果拼起来再过一个线性层。**关键在于每个头有自己的 Q/K/V 投影矩阵,所以它们会各自学到不同的关注模式。**

研究者在训练好的模型里确实观察到了分工:有些头几乎专门做指代消解,有些头盯着相邻位置,有些头负责把句法上有依赖的词连起来。当然,大部分头的作用是解释不清的——这也是可解释性研究的日常。

## 一个完整的 block

注意力只是一层里的一半。一个标准的 Transformer block 长这样:

```
x = x + Attention(LayerNorm(x))     # 注意力子层 + 残差
x = x + FFN(LayerNorm(x))           # 前馈子层 + 残差
```

三个部件各有分工:

- **残差连接**(那两个 `x +`)让梯度可以直接跨层传,这是能堆到 80 层的前提。
- **LayerNorm** 把每个位置的激活重新标准化,防止数值随层数漂走。现代模型普遍把它放在子层前面(pre-norm),因为这样更稳定。
- **前馈层(FFN)** 是一个先升维(通常 4 倍)再降维的两层网络。它占了模型总参数的三分之二左右,而它做的事和注意力互补:注意力负责在位置之间搬信息,FFN 负责在单个位置上做变换。有相当多的证据表明,**模型的「知识」主要存在 FFN 里**,这也解释了为什么后面讲 LoRA 时,要不要给 MLP 加适配器是一个重要决定。

把这个 block 堆 N 层,前面加嵌入层,后面加一个输出到词表的线性层,就是一个完整的语言模型。剩下的全是工程细节和规模。

1. 拿三个 token、d=4 的玩具例子,手写 Q、K、V 各一个 3×4 矩阵,把注意力权重算到底。这件事必须亲手算一次,之后你看任何注意力变体(多查询、滑窗、线性注意力)都会快得多。
2. 在推演里把 d 拉到最大、关掉缩放,记录最大权重和熵;再打开缩放,记录同样两个数字。用这两组数字向别人解释为什么 √d 不能省。
